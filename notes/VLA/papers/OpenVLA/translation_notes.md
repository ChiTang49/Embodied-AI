# translation_notes.md — OpenVLA (arXiv 2406.09246v3) 阅读包说明

## 1. 源文件与抽取方式

| 项目 | 说明 |
| --- | --- |
| 源文件 | `2406.09246v3.pdf`（37 页，可选中文本的 LaTeX 生成 PDF），已复制到本目录 |
| 文本抽取 | `pypdf` 文本层抽取（逐页写入中间文件后人工校对）。`pdfplumber` 仅用于版式坐标分析（行/图形对象的 bbox） |
| 图像裁切 | Poppler `pdftoppm` 以 300 DPI 按 PDF 坐标渲染局部区域，再用非白像素包围盒自动收紧并留 7px（≈1.7pt）内边距 |
| 页数覆盖 | **pp.1–37 全部覆盖**，无跳过页 |

选择 `pypdf` 而非 `pdfplumber` 做文本抽取的原因：该 PDF 的词间空格依赖字距定位，`pdfplumber` 的默认分组会把相邻单词连写（例如 "OpenVLAsetsanewstateoftheart"），而 `pypdf` 输出保留了正确词间距。

## 2. 块级锚点规则

- `S###`：正文段落（含列表型任务描述、脚注、致谢等实质性文本）
- `C###`：图注/表注原文块
- `F###`：图卡片（图片 + 原文图注 + 中文图注 + 阅读提示）
- `T###`：表卡片（图片 + Markdown 表格 + 原文表注 + 中文表注 + 阅读提示）

每个块在 `paper.md` 中形如：

```
<a id="S014"></a>
**Source:** p.4 S014

**Original:** ...

**中文:** ...
```

卡片额外带 `**Placed near:** p.X SYYY`，标明该图/表在阅读流中的插入位置（即其"首次实质性讨论"所在的正文块）。`source_map.json` 中对应字段为 `placed_after`。

## 3. 翻译原则

- 段落级对齐：不合并、不拆分原文段落（原文本身是编号列表的，仍按编号列表翻译）。
- 术语处理：模型名、数据集名、方法名（OpenVLA、RT-2-X、Octo、Diffusion Policy、SigLIP、DINOv2、LoRA、LIBERO 等）保留原文；`language grounding`、`rollout`、`embodiment` 等无共识中译的术语保留英文并首次给出说明（见正文末尾术语对照表）。
- 数值、单位、公式、引用编号 `[n]`、上下标（如 Δx、Δθ、ΔGrip）与原文保持一致；百分比格式（如 `69.7 ± 7.2 %`）按原文。
- 原文的保守措辞（may、suggests、we hypothesize、expected）在译文中保留同等不确定性，不升级为断言。

## 4. 图表处理

- 裁切框由版式坐标分析确定（先用正文/图形对象坐标定位图表的上下边界，避让正文与图注），再按非白像素收紧，因此**不含页面页眉页脚、页码与相邻正文**；图注文字单独以文本形式给出，不包含在图片里。
- 每张图/表在 `paper.md` 中都有对应卡片，且 `assets/` 中每张图片都有对应卡片（已校验：23/23 匹配）。
- 图/表内部的标签、坐标轴数值等文字保留在图像中，不再重复翻译为文本块。
- 对于跨页引用同一图表的位置（例如 Fig. 6 与 Table 2 的表注在 p.10、讨论在 p.11），卡片放在 PDF 中图注所在页，并在 `Placed near` 中注明讨论位置。

## 5. 表格列归属的校验

表 4、表 5、表 6、表 7、表 8、表 9、表 11、表 12 为多列表格，文本层抽取时的阅读顺序可能与视觉列序不同。为避免抄错数据，Markdown 版本的每个表格都做了双重校验：

1. 用 `pdfplumber` 逐词输出该行的 x 坐标，按坐标确定数值属于哪一列；
2. 用"加权平均反算"校验：把逐任务数值与试验次数（或"每个任务等权"假设）按列求平均，结果与原文给出的平均/Mean 行一致（例如表 6 四列分别反算出 33.3%、26.7%、78.3%、85.0%，与原文完全一致）。

## 6. 明确压缩或未逐字转写的内容

- **参考文献（pp.12–20，[1]–[117]）**：`paper.md` 中给出**压缩条目**（作者列表超过 4 位时压缩为"前 3 位, et al."，保留标题、出处与年份），完整条目（含全部作者，例如 [1] 约 200 位作者）见同目录 PDF 的 pp.12–20。参考文献属引用元数据，按惯例不作中译。
- **PDF 版权页信息、arXiv 侧边水印**（如第 1 页左侧竖排的 arXiv 标识）不转写、不裁切。

除上述两项外，本文没有其他被跳过的小节：方法（3.1–3.5）、实验（5.1–5.4）、讨论与局限（6）、致谢、全部附录（A–E）与全部图注/表注均已覆盖。

## 7. 已知不确定性 / 需要注意的地方

1. **原文本身的排版或拼写问题**：p.37 附录 E.1 第 4 条中 "demonstratinos" 为原文拼写错误（应为 demonstrations），译文已按正确含义翻译并在正文中标注"（原文此处拼写为 demonstratinos）"；p.29 图 10 说明中出现 "described in detail in Fig. 10"（应为 Section 5.2 / 正文），属原文笔误。p.25 有一处引号不配对（"Put Eggplant into Pot (Easy Version")，译文按语义处理。
2. **旋转文字**：Fig. 3、Fig. 5、Fig. 10 中的竖排英文标签（如 "Narrow Single-Instruction Tasks"）在文本层中顺序颠倒，因此以图像为准，未在正文中重复转写。
3. **版式交错**：p.8（Fig. 4 与左侧窄栏正文）、p.10（Table 1 / Table 2 与正文并排）等页采用"图文并排"的版式，`paper.md` 的顺序阅读版式与 PDF 的视觉版式不完全一致，但每个块都保留了 `Placed near`/页码锚点，可回查。
4. **页内脚注编号**：原文脚注在正文中是上标序号（1–8），在 Markdown 中写成 `¹`…`⁸` 或 "第 n 条脚注"，与参考文献编号 `[n]` 区分。
5. **表格栅格线**：部分表格（如 Table 3）在原 PDF 中的横线宽度小于文字宽度之外的范围，裁切框按"内容 + 规则线"取紧致边界，可能出现表格竖线贴近图片边缘的观感，属预期。
