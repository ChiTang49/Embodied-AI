## 2. 块级锚点规则

- `S###`：正文段落、章节标题、公式与脚注等实质性文本块
- `C###`：图注 / 表注块
- `F###`：图卡片（图片 + 英文图注 + 中文图注 + 阅读提示）
- `T###`：表卡片（图片 + Markdown 表格 + 英文表注 + 中文表注 + 阅读提示）

每个块在 `paper.md` 中形如：

```
<a id="S042"></a>
**Source:** p.5 S042

**Original:** ...

**中文:** ...
```

卡片额外给出 `**Placed near:** p.X SYYY`，标明该图/表在阅读流中的插入位置（其**首次实质性提及**所在块）；`source_map.json` 中对应字段为 `placed_after`。

## 3. 翻译原则

- 段落级对齐：不合并、不拆分原文段落；原文本身是编号列表（如 7 种机器人平台、各任务说明）的，译文仍按条目翻译。
- 术语处理：模型名、数据集名、方法名（π0、π0-small、PaliGemma、Gemma 2B、OXE、DROID、Bridge v2、OpenVLA、Octo、ACT、Diffusion Policy、Transfusion、DistilBERT、DiT 等）保留原文；`action expert`、`action chunk`、`flow matching`、`cross-embodiment`、`bussing` 等无共识中译的术语保留英文并给出中文说明（见正文末尾术语对照表）。
- 数学符号、数值、单位与引用编号 `[n]` 与原文一致；公式中的上下标（A_t、A^τ_t、q(A^τ_t|A_t)、v_θ、W_1…W_3 等）在 Markdown 中改写为 `A_t`、`A^τ_t`、`v_θ` 形式，语义与原文相同。
- 原文的保守措辞（may、suggests、we hypothesize、likely）在译文中保留同等不确定性，不升级为断言。
- 原文的图注编号（Fig. 1–14、TABLE I）在译文中写作「图 1」…「图 14」「表 I」。

## 4. 图表处理

- 每张图/表按 PDF 坐标裁切为**紧致区域**：不含页眉页脚、页码、图注文字与相邻正文；图注单独以文本块（C###）与卡片字段呈现。
- 裁切后做了三重自动校验：(1) 每张裁切图中**不含**字号 ≥ 9.5（正文/图注字号为 10）的文本行；(2) 与裁切窗口相交的图形对象必须完全落在窗口内（避免图形被切断）；(3) 裁切结果的非白像素比例合理（非空白）。
- 校验中出现的 5 处「clipped」告警均来自 PDF 内部的超大白色背景矩形（例如 p.8 的 `x311.7-607`、p.11 的 `x49-388.7` 背景框），其可见内容已在裁切范围内，不影响图像完整性；这些背景框超出栏宽属于原 PDF 的绘图对象特性。
- 图/表内部的标签、坐标轴数值等文字保留在图像中，不再重复翻译为文本块。
- 图 7、图 9、图 11、图 13 为矢量图表（部分标签由文本层绘制），图 6、图 8、图 10、图 12 为照片拼版，图 14 为矢量分布曲线；表 I 的横线由 PDF line 对象绘制，裁切框按其上下规则线（y 563.2–641.9）确定。

## 5. 公式与符号的处理

π0 的核心公式在原文中以居中行排版，且含有大量上下标（少量字符被 PDF 拆成独立的细小文本行）。本次处理方式：

1. 用词级坐标把被拆散的下标（如 `t`、`t+H−1`、`t′`、`0`）重新拼回公式（例如 π0、A^τ_{t+H−1}）；
2. 公式在 `paper.md` 中以纯文本形式给出（如 `L_τ(θ) = E_{p(A_t|o_t), q(A^τ_t|A_t)} ‖v_θ(A^τ_t, o_t) − u(A^τ_t|A_t)‖²`），并与上下文段落合并为同一块的续写，避免阅读中断；
3. 公式的完整版式（分式、求和符号等）请以同目录 PDF 的 p.5、p.16 为准。

## 6. 明确压缩或未逐字转写的内容

- **参考文献（pp.12–15，[1]–[60]）**：`paper.md` 中给出**压缩条目**（作者列表超过 4 位时压缩为「前 3 位作者, et al.」，保留标题、出处与年份），未逐条中译；完整条目见同目录 PDF 的 pp.12–15。`source_map.json` 中这些块（S122–S241）的 `translation` 为 `null`，并标注 `note: reference entry`。
- **PDF 版权页信息、arXiv 侧边水印**（第 1 页左侧竖排的 arXiv 标识与 `arXiv:2410.24164v4 [cs.LG] 8 Jan 2026` 水印）不转写、不裁切。
- **页脚/页眉中的页码**不转写。

除此之外，正文（pp.1–11，含全部公式与任务清单）、致谢、附录 A–E、全部图注与表注均已覆盖。

## 7. 已知不确定性 / 需要注意的地方

1. **π0 下标的复原**：PDF 中 π0 的「0」是单独排版的 7 pt 小字，文本抽取时会脱离「π」。本次按坐标把它拼回，全文统一写作 `π0`；但 Fig. 4 图注中的 「the π dataset」在 PDF 文本层内**确实没有**下标字符（该处 π 为 9.96 pt 正文大小，其后直接是 `dataset.`），因此保留为 `π` 并在此说明——结合上下文它应当指 π0 团队的自有数据集。
2. **原文笔误**：p.5 正文「benefits of incorporating VLM **pertaining**」应为 pre-training（原文拼写错误，译文按正确含义翻译并标注）；p.4 正文的「**tokens 1 corresponding**」中脚注标记位置亦为原文排版所致，译文按脚注 1 处理。
3. **连字符换行**：双栏排版中大量单词被 `-` 断行（如 `perturba-tions`、`quantiza-tion`、`speci-fication`、`em-ploys`、`alpha-betically`）。本次对全文做了统一复原（`perturbations`、`quantization`、`specification`、`employs`、`alphabetically`），仍可能有极少数词保留连字符（例如 `language-and`、`of-box`、`out-of`），它们来自原文的复合词断行，不影响语义。
4. **双栏重排**：`paper.md` 按「跨栏元素 → 左栏 → 右栏」的顺序重排，与 PDF 的视觉版式不完全一致（例如 p.8 左栏为 Fig. 7 图注、右栏为 Fig. 8 图注）；每个块都保留 `Source: p.X S###` 页码锚点，可回查原始版面。
5. **图的版式细节**：图 1、图 3 内部的矢量文字使用了 PDF 内嵌子集字体（文本层映射为 `/C12/C7/...` 等字形编号），因此图内文字只能以图像方式呈现，未提供文字转写；图 6、图 8、图 10、图 12 为照片，无文字层。
6. **表格数据**：表 I 的 7 行数据（14/32/27/13/73/86 ms）直接取自文本层，并与 PDF 中的规则线范围（x350.5–524.5）一致；未做额外计算校验。
