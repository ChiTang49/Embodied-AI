# Translation notes — RT-1 (arXiv:2212.06817v2)

## 源文件与处理方式

- **源文件：** `raw/2212.06817v2.pdf`（arXiv:2212.06817v2 [cs.RO]，31 页，letter 尺寸，可选文本 PDF，pdfTeX 生成，未加密）。
- **文本提取：** Poppler `pdftotext -layout`（逐页，用于核对行序与空格）+ `pdfplumber`（用于段落边界、字号/粗体判定与图形对象包围盒）。段落边界由"行间距 + 字号 + 首行缩进"共同判定，不采用单一空白行切分。
- **版面分析：** 旋转 90° 的 arXiv 页边标记（如 "arXiv:2212.06817v2 [cs.RO] 11 Aug 2023"）在提取时被显式过滤，避免其字符混入正文行。
- **图表提取：** 未整页截图，而是按每个图/表的实际对象包围盒做**紧密裁剪**（300 dpi），裁掉页眉、页脚、页码与无关边距；裁剪脚本为 `tmp/reader_rt1/crop_assets.py`（含全部 26 个裁剪框坐标）。

## 翻译原则与取舍

1. **段落级直译优先。** 保留原段落边界、证据链与限定语（`may`、`suggests`、`we find` 等），不合并、不摘要化、不改写为要点列表。段落顺序与原文一致（唯一的顺序调整：图/表按其"首次实质性提及处"插入，跨页图注仍标注其在 PDF 中的源页）。
2. **术语保真。** 专有名词一律保留英文原名（`RT-1`、`TokenLearner`、`FiLM`、`EfficientNet-B3`、`SayCan`、`RetinaGAN`、`Gato`、`BC-Z`、`QT-Opt`、`token`、`rollout` 等），首次出现时给出中文说明。系统术语采用领域通行译法，见 `paper.md` 的术语表。
3. **公式与数值。** PDF 中的行内数学无法按线性文本可靠还原（上下标、希腊字母、集合符号常被拆成独立文本块）。对这类段落，`**Original:**` 中的公式以行内 LaTeX 重新书写（例如 $\pi(\cdot \mid i, x_0)$、$\{x_j\}_{j=0}^{t}$、$r \in \{0,1\}$），数学含义与原式一致；中文侧同样保留公式。所有数值、百分比、括号内的相对变化量（如 `90(-2)`、`87(+64)`）按原样保留。
4. **表格。** 除给出紧密裁剪的图像外，另附 Markdown 转录表，便于检索与复制数值。多层级表头（如 Table 7 的 "Generalization" 分组、Table 13 的 Distractors 三个子列）在转录表中以列名展平表示，并在表下注明原表结构。
5. **参考文献。** 55 条书目条目保留英文原文（标准做法：书目信息不译），序号为本阅读稿按原文顺序重排；条目文本由 PDF 文本重建，个别重音符号、连字符与 URL 换行处可能残留提取痕迹（见下"已知不确定项"）。

| p.14 Table 7 / p.30 Table 13 | 表格下方的"成功率相对变化"柱状图是**带软掩膜（SMask）的栅格图**，其坐标轴与数值标签位于图像内部（不是可选文本） | 裁剪框已包含该柱状图；数值以表格正文（可选文本）为准转录 |
